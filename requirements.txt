# SkautCast — dependencies (Gemini cloud TTS pipeline)
requests                # Gemini TTS calls, follow redirects, fetch articles + images
beautifulsoup4          # parse the newsletter HTML
lxml                    # fast parser for bs4 / trafilatura
trafilatura             # extract clean article text + og:image
feedgen                 # build the podcast RSS feed
mutagen                 # read mp3 duration + size
imageio-ffmpeg          # bundled ffmpeg binary (wav -> mp3, jingle/notice mixing)
Pillow                  # generate placeholder cover art
